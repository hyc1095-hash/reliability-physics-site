這份工具在解什麼

HCI 應力量測若要反映真實電路，汲極必須串一顆負載電阻，讓 高 VD 和高 ID 不能同時發生。 這兩個互動工具就是在算「該掛多少」以及「掛了之後元件實際看到什麼」。

核心公式

RL = ( VDD − VD ) / ID( VG, VD )

純 KVL，不依賴任何元件模型。它給的是「唯一那條通過 (VD, ID) 且截距在 VDD 的負載線」，斜率恆為 −1/RL。

兩種取法（以 VDD=6 V、操作 VD=4 V 為例）

條件公式用途
(A) 最嚴苛 / bounding RL = 2 V / ID(VG=VG,max, VD=4 V) pass/fail 論證的主數據。R 最小、應力最重。
(B) 貼近實際 AC RL = 2 V / ID(VG=VG,worst, VD=4 V) 負載線正好通過實測的 HCI worst-case 偏壓點。

(A) 的 conservatism 有明確機制：掛 RA 之後，在 worst-case 閘壓下元件拉的電流遠小於 ID,max， IR drop 很小，汲極會停在遠高於 4 V 的位置。Isub 對 VD 是指數敏感，所以 (A) 不只是「電阻小」。

退化參數該卡哪一個

判準只有一句：元件在應用中是工作在飽和區還是線性區。

操作區典型應用功能參數 / criterion
飽和區 差動對輸入級、電流鏡 / 電流源 / cascode、共源共閘放大級、主動負載、gm-C transconductor、Class-A 輸出級、LDO error amp、電流舵 DAC 電流源 Idsat、gm、gds，以及 matched pair 的 mismatch drift。

ΔIdlin ≫ ΔIdsat 是 HCI 局部損傷的必然結果，不是元件異常。 HCI 損傷集中在汲極端：線性區量測時整條通道反轉，損傷區直接落在電流路徑上（等效串聯電阻 + 局部 Vt shift）→ 極敏感； 飽和區量測時電流由源極端位障 / 速度飽和決定，汲極端本來就在 pinch-off、載子濃度低 → 不敏感。典型比值 3–10 倍。

模型說明與免責

兩個工具內建的是簡化 compact model（平滑次臨界 + 速度飽和 + DIBL + CLM）， 搭配 Isub = ID·Ai(VD−Vdsat)·exp[−Bi/(VD−Vdsat)]， 損傷率取 ID(Isub/ID)m。目的是呈現幾何關係與趨勢，不是校準過的元件模型。 絕對數值請以實測的 I–V、Isub–VG 及自行萃取的 m 為準。 RL = (VDD−VD)/ID 這條關係本身不依賴模型。

What this tool solves

For an HCI stress measurement to reflect a real circuit, the drain has to be in series with a load resistor, so that high VD and high ID can never happen at the same time. These two interactive tools calculate "how big should it be" and "what does the device actually see once it's there."

The core formula

RL = ( VDD − VD ) / ID( VG, VD )

Pure KVL — it doesn't depend on any device model. It gives you "the one and only load line that passes through (VD, ID) with its intercept at VDD," whose slope is always −1/RL.

Two ways to pick it (example: VDD=6 V, operating at VD=4 V)

ConditionFormulaUse
(A) Strictest / bounding RL = 2 V / ID(VG=VG,max, VD=4 V) The primary data for a pass/fail argument. Smallest R, heaviest stress.
(B) Close to real AC RL = 2 V / ID(VG=VG,worst, VD=4 V) The load line passes exactly through the measured HCI worst-case bias point.

(A)'s conservatism has a clear mechanism: once RA is in place, the current the device draws at the worst-case gate voltage is far below ID,max, so the IR drop is small and the drain settles at a value far above 4 V. Isub is exponentially sensitive to VD, so (A) isn't just "a smaller resistor."

Three checks you must run

ItemCriterionWhat goes wrong if you skip it
MonotonicityDamage rate decreases monotonically with RL (R→0 = pure DC stress)A single bounding R covers everything — no sweep needed
RCτ[ns] = RL[kΩ] × Cnode[pF] ≪ trThe node can't keep up — you're measuring RC, not the device; the crossing point gets pushed toward high VG
Stabilitygds < 1 / RLMultiple crossing points or runaway behavior appear in the impact-ionization / snapback region

Which degradation parameter to gate on

One sentence settles it: is the device, in its application, operating in the saturation region or the linear region?

Operating regionTypical applicationsFunctional parameter / criterion
Saturation region Differential-pair input stage, current mirror / current source / cascode, cascode amplifier stage, active load, gm-C transconductor, Class-A output stage, LDO error amp, current-steering DAC current source Idsat, gm, gds, and matched-pair mismatch drift.
Idlin is not a functional parameter here
Linear region Analog switch / transmission gate, S&H sampling switch, switched-capacitor circuit switch, LDO / load-switch pass device, passive mixer switch, triode-region resistor, Class-D output stage Ron = 1/Idlin is the function itself — this must be gated on
Gray zone Ring oscillator / VCO / clock buffer (delay mainly tracks Idsat, but the tail of the transition enters the linear region), output driver / I/O (drive strength tracks Idsat; VOL/VOH and static Ron track Idlin) Both are needed

ΔIdlin ≫ ΔIdsat is an inevitable consequence of HCI's localized damage, not a device anomaly. HCI damage concentrates at the drain end: in a linear-region measurement, the whole channel is inverted, and the damaged region sits directly in the current path (as an equivalent series resistance + local Vt shift) → extremely sensitive; in a saturation-region measurement, current is set by the source-side barrier / velocity saturation, and the drain end is already pinched off with a low carrier concentration anyway → insensitive. Typical ratio: 3–10×.

Model notes & disclaimer

Both tools use a simplified compact model built in (smoothed subthreshold + velocity saturation + DIBL + CLM), paired with Isub = ID·Ai(VD−Vdsat)·exp[−Bi/(VD−Vdsat)], with the damage rate taken as ID(Isub/ID)m. The goal is to make the geometric relationships and trends clear — this is not a calibrated device model. For absolute numbers, substitute your own measured I–V, Isub–VG, and your own extracted m. The relationship RL = (VDD−VD)/ID itself doesn't depend on any model.
